# Discovery Analytics — Neo-Organic Intelligence

Six-page responsive redesign built with React 19, TypeScript, Vite, React Router, Tailwind CSS v4, GSAP/ScrollTrigger, Framer Motion and Three.js.

## Run locally

```sh
npm install
npm run dev
```

## Routes

- `/` — Home
- `/about` — About
- `/services` — Services
- `/solutions` — Solutions
- `/careers` — Careers
- `/contact` — Contact

See [docs/NEO-ORGANIC-SYSTEM.md](docs/NEO-ORGANIC-SYSTEM.md) for the six-page content audit, design system and responsive/motion notes. Original page-specific artwork is in `public/images/neo-organic/`; retained brand and source-site assets are in `public/images/discovery/`.

Contact and application forms open an addressed email draft; the site does not have a server-side form endpoint.
